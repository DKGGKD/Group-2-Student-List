# GROUP 2: STUDENT LIST SYSTEM
## A program for monitoring a student list that implements the CRUD system. It has a main controller which displays a simple interface for users to easily access the system.
------------------------------
Main Features:
1. ADD - function that allows a user to input a specified identity with name and ID validation.
2. DELETE - function that removes a user input.
3. EDIT - function that modifies existing data.
4. SEARCH - function that looks for a specified record of data within the system, case-insensitive.
-------------------------------
